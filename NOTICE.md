# Notices

MwoScrapers is an original downstream implementation of the external provider
interface used by Umbrella and Coco-compatible scraper modules.

No provider source file from CocoScrapers, ViperScrapers, or Magneto is
included. Those distributions were inspected only to establish interface
compatibility and candidate behavior. Exact artifact hashes and the result of
that review are recorded in `.upstream/upstream-observations.lock.json` and
`resources/provider-provenance.yml`.

Provider names and service names belong to their respective owners.
